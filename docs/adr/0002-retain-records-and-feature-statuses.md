# Retain records and preserve feature statuses on abandonment

V1 retains abandoned records and provides no permanent deletion, accepting that accidental entries remain in order to preserve links between ideas, projects, and features. Promotion retains the original idea, links it to one project, and cannot be undone in v1. Abandoning a project preserves its feature statuses while excluding those features from active-work views; the project must be restored before feature work resumes, preserving the point at which work stopped.

Existing titles, descriptions, and repository or issue links remain editable in every status. A promoted idea's project link is fixed; adding features or changing feature statuses within an abandoned project requires restoring the project first.
